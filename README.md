# ✈️ Airline Routes Analysis Dashboard 

## 📊 Project Overview
This project presents a **comprehensive airline performance analysis dashboard** built using **Power BI**, focusing on revenue, profitability, operational efficiency, and growth trends.

The dashboard enables **data-driven decision-making** by analyzing routes, demand patterns, delays, cancellations, and customer behavior.

---

## 🎯 Key Objectives
- Analyze **Revenue vs Profit performance**
- Identify **high and low-performing routes**
- Evaluate **seat utilization and demand efficiency**
- Monitor **delays and cancellations impact**
- Track **growth trends and business stability**
- Provide **actionable business insights**

---

## 📌 Dashboard Features

### 🔹 KPI Metrics
- 💰 Total Revenue  
- 💵 Total Profit  
- 📊 Profit Margin %  
- ✈️ Total Flights  
- ⏱ Avg Delay Time  
- ❌ Cancellation Count  
- 📉 Growth % (Revenue & Profit)

---

### 📈 Visualizations
- **Route Performance Bar Chart** → Top & bottom routes  
- **Revenue vs Cost Comparison** → Profitability gap  
- **Monthly Trend Analysis** → Flights & profit trends  
- **Scatter Plot (Revenue vs Profit)** → Efficiency analysis  
- **Multi-line Chart** → Seats Sold vs Available vs Cancellation  
- **Growth Analysis Chart** → MoM performance  
- **Donut Charts** → Route type & delay distribution  

---

### 🎯 Advanced Features
- 🔄 **Dynamic Slicers**
  - Route  
  - Month  
  - Season  
  - Day Type  
  - Route Type  

- 🧠 **Custom Measures (DAX)**
  - Profit  
  - Profit Margin %  
  - Occupancy %  
  - Growth %  
  - Delay Metrics  

- 🧩 **Tooltip Pages**
  - Detailed KPI view on hover  
  - Revenue & Flight breakdown  

- 📊 **Drill-through Analysis**
  - Route-level deep insights

## 🧠 Key Business Insights

### 1. Revenue vs Profit Gap
- High revenue but moderate profit margin (~32%)
- Indicates **high operational cost**

👉 **Action:** Cost optimization & dynamic pricing  

---

### 2. Route Performance Imbalance
- Few routes generate majority of revenue  
- Some routes underperform  

👉 **Action:** Optimize route network  

---

### 3. Low Seat Utilization
- Seats available > seats sold  

👉 **Action:** Improve demand forecasting & pricing
